# 插件页面背景验证

验证日期：2026-11-06。

插件页面与自动化任务页面共用「设置 → 外观 → 背景图片 → 侧边栏区域」的开关和底色透明度，并使用已有的图片透明度与模糊程度。标题栏、市场导航和分类栏使用同一张固定背景，滚动时遮住下方内容。关闭后恢复主题底色，不再透出会话区域的背景。

验证使用独立临时配置、DSH 0.2.2-rc.1、dshmarket 1.73.12 和无头 Edge，未修改用户运行中的配置或安装插件。

- 现有外观、原版模式与国际化测试：66 项通过。
- 插件页和自动化页的背景图层、透明度、模糊值一致。
- 会话背景开关独立；关闭侧边栏背景后，插件页及窄窗口顶部恢复不透明主题底色。
- 插件标题栏、市场导航和分类栏保持吸顶，市场旧装饰伪元素不再形成实色横条。
- 底色透明度 0% / 100%、图片透明度 0% / 100%、模糊 0% / 100%、浅色与深色切换均已验证。
- 在浅色、模糊 100% 时，同一位置的标题栏与下方页面背景均为 RGB(223, 208, 170)。图片透明度 100% 时，深色背景为 RGB(0, 0, 0)，浅色为 RGB(255, 255, 255)。
- 1280 × 900、600 × 850 窗口均已检查；窄窗口预留区域使用同样的背景与模糊，页面无横向溢出。
- 刷新后背景设置保持，外观页显示新增的适用范围说明，原版模式不应用新增样式。

刷新期间观测到上游 `dsh-client-ui-theme` 的 `normalizeFontFamily` 在 `ThemeRuntime.adopt` 中读取未定义值的 `split` 错误。切换到原版模式后刷新也能复现；背景断言和页面交互仍通过。本次未修改上游字体逻辑。
